# 📋 Fichário DS - Pesquisa no grau de satisfação no atendimento!
### 📝 Este projeto é uma atividade escolar!
### 🖥️ O programa pede o nome, idade e a nota do cliente, contabiliza as notas e informa a quantia de notas. É possivel armazenar até 50 notas.
---
## 🧮 Fórmulas utilizadas:
### 🗒️ Se a nota for 1 (Excelente) +1 no contador de repetição e +1 no contador de nota Excelente
### 🗒️ Se a nota for 2 (Bom) +1 no contador de repetição e +1 no contador de nota Bom
### 🗒️ Se a nota for 3 (Ruim) +1 no contador de repetição e +1 no contador de nota Ruim
### 🗒️ Se a nota for qualquer outro número o programa informa que a nota dada é inexistente e pede os dados novamente!
